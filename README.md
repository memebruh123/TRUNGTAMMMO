## 📥 Hướng dẫn cài đặt

### Cách 1: Tải bản chạy sẵn

1. Mở mục **[Releases](../../releases/latest)**.
2. Tải file phù hợp với thiết bị của bạn.
3. Giải nén file `.zip` nếu có.
4. Chạy file `[TEN-TOOL.exe]` hoặc file khởi động tương ứng.
5. Thiết lập cấu hình và bắt đầu sử dụng.

> [!IMPORTANT]
> Chỉ tải tool từ repository chính thức hoặc kênh công bố của TRUNGTAMMMO.VN. Không sử dụng các bản reup không rõ nguồn gốc.

### Cách 2: Chạy từ mã nguồn

```bash
# Clone repository
git clone https://github.com/USERNAME/REPOSITORY.git

# Truy cập thư mục dự án
cd REPOSITORY

# Cài thư viện — chỉnh lại theo ngôn ngữ của dự án
pip install -r requirements.txt

# Khởi chạy
python main.py
```

### Cách 3: Cài dưới dạng Userscript

Áp dụng nếu tool được viết cho **Tampermonkey** hoặc **Violentmonkey**:

1. Cài Tampermonkey trên Chrome hoặc Edge.
2. Mở file `[ten-tool.user.js]` trong repository.
3. Chọn **Raw** → **Install**.
4. Truy cập trang được hỗ trợ để sử dụng tool.

## ⚙️ Cấu hình cơ bản

| Tùy chọn | Ý nghĩa | Giá trị mẫu |
|---|---|---|
| `limit` | Số lượng tác vụ tối đa mỗi phiên | `20` |
| `delay` | Thời gian chờ giữa các tác vụ | `1500 ms` |
| `retry` | Số lần thử lại khi gặp lỗi | `2` |
| `output` | Thư mục lưu kết quả | `./output` |
| `proxy` | Bật hoặc tắt kết nối proxy hợp lệ | `false` |

```json
{
  "limit": 20,
  "delay": 1500,
  "retry": 2,
  "output": "./output",
  "proxy": false
}
```

> Các tùy chọn trên là mẫu. Hãy thay thế bằng cấu hình thực tế của tool.


```text
item_01|data_01
```

## 🛡️ An toàn & quyền riêng tư

- Kiểm tra mã nguồn trước khi chạy nếu bạn tải bản source.
- Không nhập mật khẩu, cookie, token hoặc dữ liệu nhạy cảm vào tool không rõ nguồn gốc.
- Không chia sẻ file cấu hình, nhật ký hoặc dữ liệu tài khoản lên nơi công khai.
- Không tắt phần mềm bảo mật chỉ để chạy một file chưa được xác minh.
- Nên chạy thử với dữ liệu mẫu trước khi sử dụng trong công việc thực tế.
- Luôn sao lưu dữ liệu quan trọng trước khi cập nhật phiên bản mới.

## ⚖️ Tuyên bố sử dụng

Công cụ được cung cấp cho mục đích **học tập, nghiên cứu, quản trị và tự động hóa các tác vụ hợp pháp**. Người sử dụng tự chịu trách nhiệm về cách sử dụng tool và phải tuân thủ:

- Pháp luật hiện hành.
- Điều khoản của nền tảng hoặc dịch vụ liên quan.
- Quyền riêng tư và quyền sở hữu dữ liệu của người khác.
- Giới hạn tốc độ, chống spam và các quy định an toàn.

**Không sử dụng tool để spam, lừa đảo, xâm nhập trái phép, chiếm đoạt tài khoản, đánh cắp dữ liệu hoặc gây ảnh hưởng đến người khác.**
